# React 중간고사 연습실

러닝메이트 React 중간고사(필기) 대비 사이트예요. 시험 배점(이해 30 · 코드리뷰 30 · 코드 작성 10 · 서술형 30)에 맞춰 연습해요.

- **이해**: 객관식 · 복수 정답 34문항 (바로 채점)
- **코드리뷰**: 틀린 줄 고르기 · 빈칸 채우기 32문항 (바로 채점)
- **코드 작성**: 짧은 코드 직접 쓰기 10문항 (모범답안 + 채점 포인트로 직접 채점)
- **서술형**: 개념 설명 · 이유 쓰기 24문항 (모범답안 + 채점 포인트로 직접 채점)
- **실전 모의고사**: 120분, 이해 10 · 코드리뷰 10 · 코드 작성 1 · 서술형 3 → 100점 환산

사이트: https://learningmate-lab.github.io/react-exam-lab/

`src/`는 원본 코드(`python build.py`로 한 파일 페이지를 만들어요), `data/`는 문제 데이터예요. 진행 기록은 브라우저에만 저장돼요.
